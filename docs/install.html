Install Notchex

About a minute. Notchex installs for your user only and never asks for sudo.

On this page Requirements Install After installing Avoid conflicts Optional packages Integrations Update Uninstall Troubleshooting

Requirements

  • GNOME Shell 46, 47, 48, 49 or 50. Run gnome-shell --version to check.
  • Wayland or X11
  • Any distro with a supported GNOME version: Ubuntu, Fedora, Arch, Debian, openSUSE and others

Install

Choose one method. The one-line installer is the easiest.

  1. Run the installer It checks your GNOME version, downloads the latest release, installs it and turns it on. 
    curl -fsSL https://raw.githubusercontent.com/AdityaTakuli/Notchex/main/install.sh | bash
    Want to read it first? install.sh is short.
  2. Log out and log back in On X11 you can press Alt + F2, type r and press Enter instead.
Install a specific version 
curl -fsSL https://raw.githubusercontent.com/AdityaTakuli/Notchex/main/install.sh | bash -s -- --version v2.0.0

Other options: --zip FILE installs from a local zip, and --no-enable installs without turning it on.

  1. Download the zip Get notchex@adityatakuli.shell-extension.zip from the latest release.
  2. Install it 
    gnome-extensions install --force notchex@adityatakuli.shell-extension.zip
  3. Log out and back in, then turn it on 
    gnome-extensions enable notchex@adityatakuli
  1. Clone and install You need git, make and glib-compile-schemas (part of GLib). 
    git clone https://github.com/AdityaTakuli/Notchex.git
cd Notchex
make install
  2. Log out and back in, then turn it on 
    gnome-extensions enable notchex@adityatakuli

After installing

The notch now sits at the top center of your main monitor in place of the clock. Try:

  • Hover over the notch, or press Super + N, to open the hub
  • Press Super + Space for Spotlight search
  • Play some music to see Now Playing in the notch
Only want some of it? Preferences opens on the Features page. Pick a preset (Everything, Notch only, Dock only or Look only), or switch the Notch, Dock, Spotlight and macOS look on or off one by one.

To open preferences, search "Notchex Settings" in Spotlight, use the Extensions app, or run:

gnome-extensions prefs notchex@adityatakuli

Avoid conflicts

Notchex already does what these extensions do. Running them together can cause visual glitches, like two docks:

gnome-extensions disable ubuntu-dock@ubuntu.com          # the Notchex Dock replaces it
gnome-extensions disable dash-to-dock@micxgx.gmail.com
gnome-extensions disable Vitals@CoreCoding.com           # covered by the System tab

Want to keep your current dock? Turn off the Notchex Dock on the Dock page in preferences instead.

Integrations

Google Calendar and Tasks

  1. Open Settings → Online Accounts and add your Google account.
  2. Make sure Calendar is switched on for that account.
  3. That's it. The Calendar and Tasks tabs find the account automatically, with no extra login.

Weather

On the Weather page in preferences, enter a city (Berlin), a district, coordinates (52.52,13.40) or an airport code (SFO). Leave it empty to detect your location automatically.

Claude Code usage

Install the Claude Code CLI and run claude once to sign in. The Limits tab then shows your session and weekly usage.

macOS-style icons

Get a free API key at macosicons.com, paste it on the Icons page and set Icon source to macOS-style. The key is stored in your GNOME keyring.

Update

Run the same one-line command again, then log out and back in:

curl -fsSL https://raw.githubusercontent.com/AdityaTakuli/Notchex/main/install.sh | bash

From source: git pull && make install.

Uninstall

Using traffic-light window buttons? Turn them off in preferences before uninstalling, so your original button layout and gtk.css are restored. 
curl -fsSL https://raw.githubusercontent.com/AdityaTakuli/Notchex/main/install.sh | bash -s -- --uninstall

From a source checkout: gnome-extensions disable notchex@adityatakuli && make uninstall.

Troubleshooting

Notchex doesn't show up after installing

On Wayland you have to log out and back in. Then check that GNOME sees it:

gnome-extensions list | grep notchex
The installer says my GNOME version isn't supported

Notchex supports GNOME Shell 46 to 50. Check yours with gnome-shell --version. Older releases such as Ubuntu 22.04 (GNOME 42) aren't supported.

There are two docks

Disable Ubuntu Dock or Dash to Dock (see Avoid conflicts), or turn off the Notchex Dock on the Dock page.

Super + Space doesn't open Spotlight

If you have more than one keyboard layout, GNOME uses that shortcut to switch layouts. Pick a different Spotlight shortcut on the Search page.

The Calendar tab is empty

Make sure the Google account in Online Accounts has Calendar switched on. If it's still empty, log out and back in.

There's no GPU usage

GPU usage appears only on drivers that report it (AMD and some Intel). NVIDIA isn't shown, because reading it would mean running nvidia-smi every second.

Something else is wrong

Watch the logs while you reproduce the problem, then open an issue and paste the output:

journalctl -f -o cat /usr/bin/gnome-shell
